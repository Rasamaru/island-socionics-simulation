# Simulation engine

The first prototype should be deliberately small and inspectable.

Planned components:
- agent state and individual capabilities;
- settlement and environment state;
- resource gathering and consumption;
- task allocation and cooperation;
- health, fatigue, and injury;
- event generation and logging;
- periodic state snapshots.

Start with transparent rules and tests. Add complexity only when it addresses a clearly stated modeling need. Do not encode a quadra as a single behavior profile.
